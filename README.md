# Clinical Data Science Projects Repository

**This repository aims to document all the assignment and practice projects which were part of the Clinical Data Science course from University of Colorado, aiming at Clinical Data Analysis & Data Science.


## Projects
**1. Development of a Phenotyping Algorithm to Identify Patients with Hypertension**

This involves using EHR (Electronic Health Record) data — diagnosis codes (ICD), medications, lab values, or clinical notes — to algorithmically classify patients as hypertensive. A core skill in clinical informatics and real-world evidence research.

**2. Clinical Prediction Model for ICU Mortality Risk**

Building a model (logistic regression, random forest, etc.) using ICU patient data (likely MIMIC or eICU datasets) to predict risk of death during a hospital stay. Covers feature engineering, model evaluation (AUC, calibration), and handling imbalanced clinical data.

**3. Keyword Windows & Keyword Search from Clinical Notes**

NLP-based work on unstructured clinical text — identifying relevant concepts using keyword searches and context windows (e.g., finding mentions of a symptom and checking surrounding text for negation or context). A foundational NLP technique in clinical text mining.
